## 4. Nelson-confirmed upgrade backlog (NEXT WORK)

Implement these **literal** upgrades. Do not redesign the chrome. Small incremental changes; re-read files before assuming.

### 4.1 Thought-nodes are not draggable

**Required:** Thought-nodes on the Plex must be **draggable** (reposition by drag).  

**Context today:** Canvas **pans** on empty background; nodes activate on click; bottom-dot drag creates children. Free drag of node chips themselves is missing.  

**Likely touch:** `src/Cortex.jsx` (pointer handlers, node position state) + `src/template.jsx` (node wrappers). Keep pan on empty plex; do not let node-drag steal pan incorrectly. Prefer storing per-node offsets in state/dataApi-friendly structure without hard-coding layout forever (Phase 2 layout math still deferred unless Nelson expands scope).

### 4.2 Click vs double-click / context menu for edit

**Required:**

- **Single-click** Thought-node → activate / select only.  
- **Must not** enter edit/rename on single click.  
- **Double-click** and/or **right-click → context menu** with **Edit/Rename** among other options.  

**Context today:** Selecting a node updates notes/title panels; there is no proper rename-on-double-click or node context menu. Menu bar already has Thought → Rename/Edit (F2) as a stub toast path in places — wire real rename UI and match TB7 expectations from mockup where possible.

**Context menu** should list at least edit/rename; expand with other sensible Thought actions already present in the Thought menu (copy, forget, etc.) as stubs or real handlers without inventing a new IA.

### 4.3 Dialog-boxes need to be resizable

**Required:** Dialogs must be **user-resizable** (drag edges/corners), not fixed card sizes only.  

**Context today:** Dialogs are centered fixed-width panels from the mockup template.  

**Approach:** Add resize handles or CSS `resize` + min dimensions; persist size in component state for the session; keep draggable title bars if already present (Create Child already has drag). Apply consistently across Preferences, file browser, New Brain, etc.

### 4.4 Remove hyperlink to www.thebrain.com → GitHub page

**Required:** Help (or wherever) link that opened `https://www.thebrain.com` must **not** point there. Point to a **GitHub page** instead.  

**Context today:** `Cortex.jsx` menu handler opens TheBrain.com for the Help item containing `www.TheBrain.com`.  

**Action for successor:** Confirm the exact GitHub URL with Nelson if not already provided; until confirmed, use a clearly named placeholder constant at top of config (e.g. `GITHUB_PROJECT_URL`) and ask Nelson once — do not guess a wrong repo. If Nelson supplies URL in chat after reboot, wire it immediately.

### 4.5 Search input text-box must be editable

**Required:** The **Search** field on the Plex (and any non-functional search boxes in the Thought panel Search tab) must accept typing.  

**Context today:** Plex bottom-left “Search” control is largely a non-input chrome block; Thought tab Search has a non-editable bar.  

**Action:** Replace with real `<input>` bound to state; on Enter show toast or filter stub results via `dataApi`/local list. Full search index remains Phase 2.

### 4.6 Panels: dock / undock / resize / close / open via menu

**Required:** Notes and Thought panels must support:

| Capability | Behavior |
|------------|----------|
| Dock | Default: docked in bottom split (current layout) |
| Undock | Float as a **dialog-like** window (movable; treat like dialog chrome) |
| Resizable | Both docked splitters (already partial) **and** undocked floating frames |
| Close | Hide panel |
| Open | Restore visibility |

**Menu wiring (explicit):**

- Main menu → **Thought → Open Notes Window** → open/show Notes panel (docked or last undocked mode)  
- Main menu → **Thought → Open Thought Window** → open/show Thought panel  

**Context today:** Bottom split has Notes | Thought with vertical/horizontal resize handles; menu items for Open Notes/Thought Window are stub toasts. No undock/float, no close that removes from layout.

**Implementation notes:** Track `notesPanel: { visible, mode: 'docked'|'float', width/height/x/y }` and same for thought panel. Floating mode reuses dialog shell styling. Closing docked panel should expand Plex; opening restores split.
